# AI-Powered CRM Automation System

An intelligent CRM automation solution built using **n8n, Google Gemini AI, and HubSpot** to automate customer data processing and CRM operations.

## Project Overview

This project demonstrates how AI and workflow automation can reduce manual CRM tasks, process incoming customer information, and streamline business operations.

## Technologies Used

- n8n – Workflow Automation
- Google Gemini AI – AI-powered text processing
- HubSpot – CRM Platform
- Webhooks – Workflow integration
- REST APIs – Application communication
- JSON – Structured data exchange

## Key Features

- Automated workflow execution using n8n.
- AI-powered data processing with Google Gemini.
- HubSpot CRM integration.
- Webhook-based data handling.
- Automated CRM operations.
- Reduced manual data entry and repetitive tasks.

## Workflow Architecture

**Input → Webhook → Gemini AI → Data Processing → HubSpot CRM**

## Setup Instructions

1. Install or run n8n.
2. Configure Google Gemini API credentials.
3. Configure HubSpot credentials in n8n.
4. Import the workflow JSON file.
5. Update the required credentials and test the workflow.
